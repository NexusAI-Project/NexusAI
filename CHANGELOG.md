# Changelog

All notable changes to NexusAI will be documented in this file.

## [0.1.0] - 2026-07-04

### Added

- Added the NexusAI Foundation v0.1 Python package structure.
- Added the minimal bootable `nexusai_core` core.
- Added `NexusHeart` for identity and purpose metadata.
- Added `NexusMemory` for simple in-memory key-value storage.
- Added `ModuleRegistry` for future module registration.
- Added `EventBus` for internal core events.
- Added a standard-library boot test using `unittest`.
- Added Python project configuration through `pyproject.toml`.
