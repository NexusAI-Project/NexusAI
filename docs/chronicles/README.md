# The Chronicles of NexusAI

The Chronicles of NexusAI are the historical memory of the project.

They are not only technical notes. They are a record of meaningful milestones: the moments where NexusAI changed shape, gained structure, received a new foundation, or crossed an important threshold.

---

## Purpose

The chronicles exist to preserve the story behind the architecture.

They help future contributors understand:

- why the project exists;
- when important phases happened;
- what each milestone meant;
- how the project evolved from idea to structure;
- why certain decisions were made.

NexusAI is built as a long-term ecosystem. A long-term ecosystem needs more than code. It needs memory.

---

## Technical Memory vs Historical Memory

NexusAI keeps two kinds of memory in the repository.

### Technical memory

Technical memory explains how the project works.

Examples:

- `README.md`
- `PROJECT_CONTEXT.md`
- architecture documents
- tests
- changelogs
- implementation notes

Technical memory is practical, operational, and direct.

### Historical memory

Historical memory explains what the project became and why each step mattered.

Examples:

- foundation chronicles;
- milestone stories;
- symbolic project records;
- long-term evolution notes.

Historical memory is narrative, reflective, and human.
