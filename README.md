A living AI framework designed to think, evolve and grow.

**Embellir - Enrichir - Evoluer**

NexusAI is a long-term intelligent ecosystem project. It is designed around a central AI vision, modular components, evolving memory, integrations, automation, and future-ready tooling.

## Development

Install the project in development mode:

```bash
python -m pip install -e .
```

Run the NexusAI core:

```bash
python -m nexusai_core.main
```

Run the test suite:

```bash
python -m unittest discover -s tests
```
